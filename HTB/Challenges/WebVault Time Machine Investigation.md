# WebVault Time Machine Investigation

## Description

Following the discovery of suspicious negative reviews targeting TechCorp's XyloPhone product line, investigators have identified a website "alexmorgan-reviews.net" that appears to be the source of coordinated negative review campaigns. The reviews are well-written and appear legitimate, but the consistently negative sentiment across all TechCorp products raises suspicions of corporate espionage. Your task is to investigate this website's history using the WebVault Internet Archive and uncover any hidden connections that might explain the bias against TechCorp products.

## Solution

Launch the instance and copy the IP address. Using the browser visit the website hosted using the IP address.

Website is called WebVault, Internet Time Machine where it shows the webpage of Alex morgan's reveiw (https://alexmorgan-reviews.net) which targets Techcorp's XyloPhone product line. It also shows the web archive of the webpage on different dates, 4 snapshots between August 15, 2023 - March 18, 2024. 

On the snapshot of August 15, 2023, ALex reveals he is a former Marketing Specialist of Rivaltech, meaning he is targetting Techcorp for rivaltech.

The format of the flag is HTB{Job_Position_Company}.
