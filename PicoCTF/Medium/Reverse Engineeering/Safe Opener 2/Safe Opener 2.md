# Safe Opener 2

## Description

What can you do with this file?

I forgot the key to my safe but this file
is supposed to help me with retrieving the lost key. Can you help me unlock my safe?

## Solution

Download the .class file using the hyperlink in the descritpion. 

A .class file is a compiled java file that contains java bytecode, a highly optimized & platform-independent code. It is an intermediate code designed to be executed by Java Virtual Machine (JVM).

Since it is compiled and non-human readable. ```strings``` can used to print out the human readable parts of the file.

```
strings <filename>
```

Prints all human readable parts of the file, thus also printing the flag.
